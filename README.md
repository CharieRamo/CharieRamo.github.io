# Charie A. Ramo – Portfolio

Static portfolio site (no build step) with four focus views: HR Operations, Executive Support, Office & Workplace Operations, Administration & Front Desk.

## Publish on GitHub Pages
1. On GitHub, create a **public** repository named `YOUR-USERNAME.github.io` (or any name, e.g. `website`, to get `YOUR-USERNAME.github.io/website`).
2. Upload `index.html`, `style.css`, `script.js` (Add file → Upload files) and commit.
3. Repo **Settings → Pages → Build and deployment → Source: Deploy from a branch → `main` / root → Save**.
4. Wait 1–2 minutes, then open your link.

## Share a tailored link per application
- HR roles: `https://YOUR-USERNAME.github.io/?focus=hr`
- Executive support: `?focus=exec`
- Office / workplace: `?focus=office`
- Admin / front desk: `?focus=admin`

## Edit content
All text lives at the top of `script.js` (`JOBS`, `FOCUS`, `TOOLS`). Add real numbers (e.g. % faster, AED saved) to results where you have them.
